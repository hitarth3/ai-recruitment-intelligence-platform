# Resume Chat AI Module

## Overview
This module will provide an interactive AI assistant allowing recruiters to ask natural language questions about candidate resumes.

## Future Responsibilities
- Integrate with Google Gemini API / Hugging Face models for RAG (Retrieval-Augmented Generation).
- Enable conversational Q&A on candidate background (e.g., "Summarize candidate's leadership experience in Python").
- Provide quick summaries and red-flag analysis for recruiters.
